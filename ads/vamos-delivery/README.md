# إعلان VAMOS: من القطن حتى باب بيتك

ريل موشن 1080×1920، مدته 28 ثانية بـ 30fps، والصوت مظبوط على −14 LUFS. النسخة النهائية: `vamos-delivery.mp4`

| المشهد | الوقت |
|---|---|
| Hook: رحلة تيشيرتك | 0–3 |
| 01 القطن ١٠٠٪ | 3–6 |
| 02 الخياطة | 6–9.5 |
| 03 الطباعة + ٤ ألوان | 9.5–13.5 |
| 04 التغليف | 13.5–17 |
| 05 التوصيل + خارج الكويت | 17–20.5 |
| ٢٩ دولة | 20.5–24.3 |
| CTA: اطلب الآن + الموقع | 24.3–28 |

## التعديل
- **التوقيتات** في `timeline.json`، والصورة والصوت الاتنين بيقروا منه.
- **النصوص** في `index.html` داخل `setWords(...)`. الكلمة اللي بين `[...]` بتاخد تظليل lime، و`_` معناها مسافة جوه التظليل.
- **معاينة live:** `python3 -m http.server`، وبعدها افتح `index.html`.

## الـ Render
```bash
python3 sound.py
node render.mjs --stills 0,4,8,12,16,20,24,27 --cols 4
node render.mjs --audio out/sfx.wav --out out/video.mp4
```
- `python3 sound.py` بيطلّع `out/sfx.wav`.
- `--stills` بيعمل contact sheet للمراجعة.
- السطر التالت بيعمل الفيديو كامل بالصوت.

الـ render محتاج Playwright وffmpeg. لو Playwright متسطب global، شغّل بـ `NODE_PATH=$(npm root -g)`.

## الـ Assets
`assets/` فيها التيشيرتات من غير خلفية، ونسخة "blank" من غير الطباعة لمشهد الطابعة، والأعلام اتقصّت من ستوري الدول. كلها طالعة من الصور الأصلية.
